## Subir y publicar

1. Descomprimí el ZIP.
2. Creá un repositorio en GitHub llamado, por ejemplo, cpk-comparacion-tgbt, o abrí el repositorio que quieras actualizar.
3. Elegí Add file > Upload files.
4. Subí los archivos de esta carpeta directamente a la raíz del repositorio. No subas el ZIP ni una carpeta contenedora. index.html debe verse en la raíz.
5. Confirmá con Commit changes en la rama main. Si el repositorio ya tiene un index.html, estos archivos reemplazan su página principal.
6. En Settings > Pages, en Source elegí Deploy from a branch.
7. Elegí main y /(root), y presioná Save.
8. Cuando finalice la publicación, abrí la dirección indicada por GitHub en Settings > Pages.

La URL tendrá este formato:
https://TU-USUARIO.github.io/cpk-comparacion-tgbt/

Si .nojekyll no aparece al subir desde el equipo, podés crearlo con Add file > Create new file: nombre .nojekyll, contenido vacío.

## Actualizar

Reemplazá index.html por una nueva versión y confirmá los cambios.
Con la publicación por rama configurada, GitHub Pages actualizará el sitio.

- Rojo: no equivalentes directos o sin equivalente publicado.
